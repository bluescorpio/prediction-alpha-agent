# 3 分钟录屏脚本

对着本地页面 http://localhost:3000/ 录。开录前确认：未连接钱包，三条预置信号都在，BTC / SOL 的链上 followers 不是占位符。旁白用口语，画面切到光标所在的那一块。

| 时间 | 画面 | 旁白 |
| --- | --- | --- |
| 0:00–0:25 | 先不要出页面。黑底或一页纸：左边写「预测市场：BTC 站上 10 万美元，72%」，右边写「永续：现价和资金费率还在平常水平」。 | 同一件事，两个市场各标各的价。预测市场说这件事概率很高，永续那边的定价还没跟上。平时没有人专门盯这条缝。 |
| 0:25–0:50 | 切到仪表盘标题「Prediction Alpha Agent」，慢慢扫过三条信号的问题和 direction。先别点按钮。 | 所以做了一个不休息的情报台。它把两边的价对齐，分歧够大就出一条信号，再写成一张能读完的情报卡。 |
| 0:50–1:20 | 停在第一条「样例：BTC 站上 100000 美元」。依次点到 evidence 三行、suggestedAction、riskNotes。 | 这是已经算好的一条。市场隐含概率 0.72，模型概率接近 0，z 大于 8，方向是预测市场偏贵。下面这张卡写了建议动作和风险。没有模型密钥时，这段是模板，不当成投资建议。 |
| 1:20–1:45 | 把镜头移到「链上 followers」和「链上 outcome」。再打开终端，跑 `solana account <第一条 signalPda> --url devnet`，账户 owner 是程序地址。 | 数字不是页面自己编的。这条信号已经登记在 devnet 的 AlphaDesk 上，刷新之后还是从链上读回来。 |
| 1:45–2:20 | 点「Select Wallet」，连 Phantom（devnet）。「我已跟随的信号」从「请先连接钱包」变成这个钱包自己的列表。对一条尚未跟随的信号点「跟随」，钱包弹签名，确认。按钮变成「已跟随」，出现 tx，链上 followers 加 1。列表里出现这道题。 | 跟随会请你签名。确认之后，程序为这个钱包建一条 follow 记录，并把 followers 加一。换一个钱包，列表会换；断开钱包，就不再按用户去查。 |
| 2:20–3:00 | 回到三条卡的全貌，最后停在程序地址 `5L7SHJT5uK59tFyYNzuA7qrGorxyEwcXur4Gi28HhyYh`。 | 黑客松这一版先把分歧摊开，并把跟随写上链。接下来用同一张卡做持续选题，补上拥挤度和未反应窗口，结算后再把对错写进 outcome。战绩留在链上，谁都能核对，所以它不会停在这三分钟。 |

录的时候如果签名超过几秒，把 1:45 那段的等待剪掉，把省下的时间留给最后的程序地址。
